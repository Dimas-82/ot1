## 🚀 Быстрый старт (3 шага)

### 1. Установите Python 3.10+
- Скачайте с https://www.python.org/downloads/
- **ВАЖНО:** При установке отметьте ✅ "Add Python to PATH"

### 2. Запустите установку
```cmd
Откройте папку: backend
Дважды кликните: setup.bat
Дождитесь завершения (2-5 минут)
```

### 3. Запустите приложение
```cmd
Дважды кликните: run.bat
Откройте браузер: http://localhost:8000
```

### 4. Войдите в систему
```
Логин: admin
Пароль: admin123
```

## 🛠️ Архитектура

### Frontend (встроенный):
- **React 18** через CDN (jsdelivr)
- **Babel** для JSX в браузере
- Все стили встроены в HTML
- Данные хранятся в localStorage
- **Не требует сборки через npm!**

### Backend:
- **Python 3.10+**
- **FastAPI** — веб-фреймворк
- **SQLAlchemy** — ORM
- **SQLite** — база данных
- **JWT** — аутентификация
- **Pydantic** — валидация

### Структура:
```
backend/
├── main.py              # FastAPI backend
├── requirements.txt     # Зависимости Python
├── setup.bat           # Установка
├── run.bat             # Запуск
├── reset.bat           # Сброс БД
├── dist/
│   └── index.html      # ⭐ Встроенный React frontend
├── data/
│   └── rcs_ot.db       # SQLite база данных
├── logs/               # Логи
└── venv/               # Виртуальное окружение
```

## ⚙️ Конфигурация

### Файл `.env`:
```ini
# База данных
DATABASE_URL=sqlite:///./data/rcs_ot.db

# Секретный ключ (ОБЯЗАТЕЛЬНО ИЗМЕНИТЕ!)
SECRET_KEY=change-this-to-random-string-min-32-chars-long-in-production

# Режим отладки
DEBUG=true
```

### Изменение SECRET_KEY:
```python
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

## 🔐 Безопасность

### Для production:
1. ✅ Измените `SECRET_KEY` в `.env`
2. ✅ Измените пароли тестовых пользователей
3. ✅ Отключите `DEBUG=true` в `.env`
4. ✅ Настройте firewall Windows
5. ✅ Используйте HTTPS (дополнительная настройка)
6. ✅ Регулярно делайте резервные копии

### Резервное копирование:
```cmd
# Скопируйте папки:
backend/data/      # База данных
backend/.env       # Конфигурация
```

## 🆘 Решение проблем

### Python не найден
→ Переустановите Python с "Add to PATH"

### Ошибка установки
→ Запустите cmd от имени администратора

### Порт 8000 занят
→ Измените порт в `backend/main.py` (строка с `uvicorn.run`)

### База данных не создается
→ Запустите `backend/reset.bat`

### Frontend не загружается
→ Убедитесь, что файл `backend/dist/index.html` существует

## 📊 API Endpoints

### Аутентификация:
- `POST /api/auth/login` — вход
- `GET /api/auth/me` — текущий пользователь

### Модули:
- `GET /api/users` — пользователи
- `POST /api/users` — создать пользователя
- `PUT /api/users/{id}` — обновить пользователя

### Инциденты:
- `GET /api/incidents` — список
- `POST /api/incidents` — создать
- `PUT /api/incidents/{id}` — обновить

### Инструктажи:
- `GET /api/trainings` — список
- `POST /api/trainings` — создать

### СИЗ:
- `GET /api/ppe` — список выдач
- `POST /api/ppe` — выдать СИЗ

### Медосмотры:
- `GET /api/med-exams` — список
- `POST /api/med-exams` — запланировать

### Модули:
- `GET /api/modules` — список модулей
- `PUT /api/modules/{id}/toggle` — включить/отключить

### Маршруты:
- `GET /api/routes` — список
- `POST /api/routes` — создать
- `PUT /api/routes/{id}` — обновить
- `DELETE /api/routes/{id}` — удалить

### Аудит:
- `GET /api/audit` — журнал действий

### Настройки:
- `GET /api/settings` — настройки
- `PUT /api/settings/{key}` — обновить

### Статистика:
- `GET /api/dashboard/stats` — статистика дашборда
