# ✅ Исправление проблемы с кодировкой завершено!

## 🔧 Что было исправлено

Проблема была в том, что .bat файлы содержали русские символы, которые Windows cmd не мог корректно обработать из-за различий в кодировках (UTF-8 vs CP866).

**Решение:** Все .bat файлы переписаны на английском языке.

## 🚀 Как использовать (пошаговая инструкция)

### Шаг 1: Установите Python
1. Скачайте Python 3.10+ с https://www.python.org/downloads/
2. **ВАЖНО:** При установке отметьте галочку **"Add Python to PATH"**
3. Проверьте установку:
   ```cmd
   python --version
   ```

### Шаг 2: Запустите установку
1. Откройте папку `backend` в Проводнике
2. Дважды кликните на файл **`setup.bat`**
3. Дождитесь завершения (2-5 минут)

Вы увидите сообщение:
```
==========================================
  Installation completed successfully!
==========================================

Login credentials:
  Login: admin
  Password: admin123

  Login: safety
  Password: safety123

[IMPORTANT] Change passwords on first login!

To start the application run: run.bat
```

### Шаг 3: Запустите приложение
1. Дважды кликните на файл **`run.bat`**
2. Дождитесь сообщения:
   ```
   ==========================================
     Server started!
   ==========================================
   
   Open browser and go to:
     http://localhost:8000
   ```
3. Откройте браузер: **http://localhost:8000**

### Шаг 4: Войдите в систему
```
Логин: admin
Пароль: admin123
```

## ⚠️ Важные замечания

### Безопасность
1. **Измените пароль** администратора при первом входе
2. **Измените SECRET_KEY** в файле `backend/.env`
3. Для production отключите `DEBUG=true` в `.env`

### Резервное копирование
Регулярно копируйте:
- `backend/data/` - база данных
- `backend/.env` - конфигурация

### Требования
- Windows 10/11 (64-bit)
- Python 3.10 или выше
- 2 GB RAM минимум
- 1 GB свободного места

## 🆘 Решение проблем

### Python не найден
→ Переустановите Python с "Add to PATH"

### Ошибка установки
→ Запустите cmd от имени администратора

### Порт 8000 занят
→ Измените порт в `backend/main.py` (строка с `uvicorn.run`)

### База данных не создается
→ Запустите `backend/reset.bat`

### Подробная помощь
→ См. файл `backend/README_WINDOWS.md`
