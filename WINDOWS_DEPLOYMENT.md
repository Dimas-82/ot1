## 🎯 Возможности системы

### Функциональность (полностью рабочая)

1. **Аутентификация и авторизация**
   - Вход по логину/паролю
   - JWT токены
   - Роли: admin, safety-engineer, manager, worker, auditor

2. **Управление инцидентами**
   - Регистрация (4 типа: инцидент, несчастный случай, предпосылка, опасное условие)
   - Оценка тяжести (low, medium, high, critical)
   - Статусы: registered, investigating, completed, closed
   - Автоматическая генерация номеров (INC-2024-001)

3. **Инструктажи**
   - 5 типов: introductory, primary, repeat, unscheduled, targeted
   - Планирование и учет участников
   - Статусы: scheduled, completed, cancelled

4. **СИЗ (Средства индивидуальной защиты)**
   - Выдача работникам
   - Учет предметов (наименование, количество, размер)
   - Контроль сроков замены

5. **Медицинские осмотры**
   - 4 типа: preliminary, periodic, pre-shift, extra
   - Планирование и результаты
   - Контроль просроченных осмотров

6. **Управление модулями**
   - Включение/отключение модулей
   - Просмотр прав доступа
   - Автоматическая запись в аудит

7. **Route Manager**
   - CRUD маршрутов API
   - Привязка к модулям и ролям
   - Приоритеты маршрутов

8. **Управление пользователями**
   - Создание пользователей
   - Назначение ролей
   - Блокировка/разблокировка

9. **Журнал аудита**
   - Полная запись всех действий
   - Фильтрация и поиск
   - Временные метки и IP-адреса

10. **Настройки системы**
    - Конфигурация через UI
    - Категории: Общие, Безопасность, Аудит, Уведомления, Модули

11. **Уведомления**
    - In-app уведомления
    - Счетчик непрочитанных
    - Автоматические уведомления при создании инцидентов

## 📦 Установка на Windows

### Вариант 1: Автоматическая установка (рекомендуется)

```cmd
1. Откройте папку backend
2. Запустите setup.bat
3. Дождитесь завершения (2-5 минут)
4. Запустите run.bat
5. Откройте http://localhost:8000
```

### Вариант 2: Быстрый старт

```cmd
1. Запустите quickstart.bat
2. Откройте http://localhost:8000
```

### Вариант 3: Ручная установка

```cmd
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python -c "from main import init_data; init_data()"
python main.py
```

## 📝 Примечания

### Для production
1. Измените `SECRET_KEY` в `.env`
2. Измените пароли тестовых пользователей
3. Отключите `DEBUG=true` в `.env`
4. Настройте firewall Windows
5. Используйте HTTPS (дополнительная настройка)
6. Регулярно делайте резервные копии

### Ограничения
- SQLite подходит для небольших организаций (до 100 пользователей)
- Для production рекомендуется PostgreSQL
- Frontend работает с localStorage (демо-режим)
- Для полной интеграции с API требуется доработка frontend
