## 🔧 Требования

### Обязательные
- **Операционная система:** Windows 10/11 (64-bit)
- **Python:** 3.10 или выше
- **RAM:** минимум 2 GB
- **Диск:** минимум 1 GB свободного места

### Проверка Python

1. Откройте командную строку (cmd) или PowerShell
2. Выполните команду:
   ```
   python --version
   ```
3. Должна отобразиться версия Python 3.10 или выше

**Если Python не установлен:**
1. Скачайте с [python.org](https://www.python.org/downloads/)
2. При установке **ОБЯЗАТЕЛЬНО** отметьте галочку **"Add Python to PATH"**
3. Завершите установку и проверьте снова

## 🚀 Быстрая установка

### Шаг 1: Скачивание проекта

Скачайте или клонируйте проект в любую папку, например:
```
C:\Projects\rcs_ot\backend
```

### Шаг 2: Установка

1. Откройте папку `backend` в Проводнике
2. Дважды кликните на файл **`setup.bat`**
3. Дождитесь завершения установки (2-5 минут)

**Что происходит при установке:**
- ✓ Создаётся виртуальное окружение Python
- ✓ Устанавливаются все зависимости
- ✓ Создаются необходимые папки (data, logs, uploads, backups)
- ✓ Создаётся конфигурационный файл `.env`
- ✓ Инициализируется база данных
- ✓ Создаются тестовые пользователи

### Шаг 3: Проверка установки

После завершения установки вы увидите:
```
==========================================
  Установка завершена успешно!
==========================================

Учетные данные для входа:
  Логин: admin
  Пароль: admin123

  Логин: safety
  Пароль: safety123

[ВАЖНО] Измените пароли при первом входе!

Для запуска приложения выполните: run.bat
```

## ▶️ Запуск приложения

### Запуск сервера

1. Откройте папку `backend` в Проводнике
2. Дважды кликните на файл **`run.bat`**
3. Дождитесь появления сообщения:
   ```
   ==========================================
     Сервер запущен!
   ==========================================
   
   Откройте браузер и перейдите по адресу:
     http://localhost:8000
   ```

4. Откройте браузер и перейдите по адресу: **http://localhost:8000**

### Вход в систему

Используйте один из тестовых аккаунтов:

| Роль | Логин | Пароль |
|------|-------|--------|
| Администратор | `admin` | `admin123` |
| Инженер по ОТ | `safety` | `safety123` |

### Остановка сервера

Для остановки сервера:
1. Перейдите в окно командной строки, где запущен сервер
2. Нажмите **Ctrl+C**
3. Подтвердите остановку, нажав **Y**

## ⚙️ Настройка

### Файл конфигурации .env

Откройте файл `.env` в текстовом редакторе (Блокнот, Notepad++ и т.д.)

#### Основные параметры:

```ini
# База данных
DATABASE_URL=sqlite:///./data/rcs_ot.db

# Секретный ключ (ОБЯЗАТЕЛЬНО ИЗМЕНИТЕ!)
SECRET_KEY=your-secret-key-change-this-in-production

# Режим отладки (false для production)
DEBUG=true
```

#### Изменение секретного ключа

**ВАЖНО:** Измените `SECRET_KEY` перед использованием в production!

Для генерации случайного ключа:
```python
python -c "import secrets; print(secrets.token_urlsafe(32))"
```

Скопируйте сгенерированную строку и вставьте в `.env`:
```ini
SECRET_KEY=ваш-сгенерированный-ключ
```

### Изменение порта сервера

По умолчанию сервер работает на порту **8000**.

Для изменения порта отредактируйте `main.py`, найдите строку:
```python
uvicorn.run(app, host="0.0.0.0", port=8000)
```

Измените `port=8000` на нужный порт, например `port=8080`.

## 🔄 Обновление

### Обновление приложения

1. Остановите сервер (Ctrl+C в окне запуска)
2. Замените файлы проекта на новые версии
3. Запустите `setup.bat` для обновления зависимостей
4. Запустите `run.bat`

### Резервное копирование

Перед обновлением рекомендуется создать резервную копию:

1. Скопируйте папку `data/` (база данных)
2. Скопируйте папку `uploads/` (загруженные файлы)
3. Скопируйте файл `.env` (конфигурация)

### Восстановление из резервной копии

1. Остановите сервер
2. Замените папки `data/` и `uploads/` из резервной копии
3. Замените файл `.env`
4. Запустите сервер

## 🔍 Устранение неполадок

### Ошибка: "Python не найден"

**Решение:**
1. Установите Python с [python.org](https://www.python.org/downloads/)
2. При установке отметьте **"Add Python to PATH"**
3. Перезагрузите компьютер
4. Проверьте: `python --version`

### Ошибка: "Не удалось создать виртуальное окружение"

**Решение:**
1. Удалите папку `venv` (если существует)
2. Запустите `setup.bat` снова
3. Если ошибка повторяется, проверьте права доступа к папке

### Ошибка: "Port 8000 already in use"

**Решение:**
1. Измените порт в `main.py` (см. раздел "Настройка")
2. Или остановите другое приложение, использующее порт 8000

### Ошибка: "ModuleNotFoundError"

**Решение:**
1. Убедитесь, что виртуальное окружение активировано
2. Запустите: `venv\Scripts\activate`
3. Установите зависимости: `pip install -r requirements.txt`

### База данных не создается

**Решение:**
1. Удалите файл `data/rcs_ot.db` (если существует)
2. Запустите `setup.bat` снова
3. Проверьте права доступа к папке `data/`

### Ошибка при входе в систему

**Решение:**
1. Проверьте правильность логина и пароля
2. Убедитесь, что база данных создана (файл `data/rcs_ot.db` существует)
3. Если нужно сбросить базу данных:
   - Удалите файл `data/rcs_ot.db`
   - Запустите `setup.bat`

### Сервер не запускается

**Решение:**
1. Проверьте, что файл `main.py` существует
2. Проверьте логи в папке `logs/`
3. Запустите вручную для просмотра ошибок:
   ```
   venv\Scripts\activate
   python main.py
   ```

## 🔒 Безопасность

### Рекомендации для production

1. **Измените SECRET_KEY** в файле `.env`
2. **Измените пароли** тестовых пользователей
3. **Отключите DEBUG режим** в `.env`:
   ```ini
   DEBUG=false
   ```
4. **Настройте firewall** Windows для порта 8000
5. **Используйте HTTPS** (требуется дополнительная настройка)
6. **Регулярно делайте резервные копии** базы данных

### Изменение паролей пользователей

Через веб-интерфейс (только администратор):
1. Войдите под администратором
2. Перейдите в раздел "Пользователи"
3. Нажмите на пользователя
4. Измените пароль
