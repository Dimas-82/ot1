# АСУ "Охрана труда" - Быстрый старт на Windows

## 🚀 Установка за 3 шага

### Шаг 1: Установите Python
1. Скачайте Python 3.10+ с https://www.python.org/downloads/
2. **ВАЖНО:** При установке отметьте галочку "Add Python to PATH"
3. Проверьте: откройте cmd и выполните `python --version`

### Шаг 2: Запустите установку
1. Откройте папку `backend` в Проводнике
2. Дважды кликните на файл **`setup.bat`**
3. Дождитесь завершения (2-5 минут)

### Шаг 3: Запустите приложение
1. Дважды кликните на файл **`run.bat`**
2. Откройте браузер: **http://localhost:8000**

## ⚠️ Важно

- Измените пароль администратора при первом входе
- Измените `SECRET_KEY` в файле `backend/.env`
- Делайте регулярные резервные копии папки `backend/data/`

## 🆘 Проблемы?

1. Python не найден → Переустановите Python с "Add to PATH"
2. Ошибка установки → Запустите cmd от имени администратора
3. Порт занят → Измените порт в `backend/main.py`

Подробности см. в разделе "Устранение неполадок" файла `backend/README_WINDOWS.md`
