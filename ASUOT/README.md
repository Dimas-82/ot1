# АСУ ОТ — Автоматизированная система управления охраной труда (РФ)
Веб-приложение на Python/Flask для инженера по охране труда. SQLite, роли: администратор / инженер по ОТ / работник, светлая и тёмная темы.

## Возможности
- Подразделения: отдел, цех, участок, бригада — ручной ввод, иерархия
- Профессии: ручной ввод + выбор из базы профстандартов (актуально на 2026 г.)
- Инструктажи по ПП РФ №2464: авто/ручной расчёт сроков (3/6 мес., проверка знаний 1 год), журнал
- Инциденты и расследования: сроки по ст.229.2 ТК РФ (3/15 дней), авто-протокол + акт формы Н-1 (Приказ 776н)
- Экзамены по электробезопасности: председатель/члены/проверяемые, авто-протокол (Приказы 900н, 1062н), периодичность 1/3 года
- СИЗ/спецодежда/обувь: учёт выдачи, план замены, контроль (Приказы 766н/767н)
- Календарь задач, уведомления работнику, автопланирование напоминаний
- Права: работник видит только свою страницу; расширенный доступ даёт администратор, подтверждает инженер по ОТ
