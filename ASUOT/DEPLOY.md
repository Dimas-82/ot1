# Инструкция по развертыванию АСУ ОТ

## Требования
Python 3.9+ (на сервере python3), SQLite (входит в Python), сетевой порт 8080 (можно изменить через ASUOT_PORT).

## 1. Ubuntu (комплексное развертывание, systemd + gunicorn)
```bash
git clone <ваш-репозиторий> /tmp/asuot && cp -r /tmp/asuot/ASUOT /opt/ASUOT
cd /opt/ASUOT && sudo ./deploy.sh
sudo systemctl status asuot        # проверка
sudo journalctl -u asuot -f        # логи
```
Скрипт ставит python3-venv, создаёт venv, БД, сервис `asuot`, автозапуск. Доступ: http://IP_СЕРВЕРА:8080

## 2. Windows
```bat
cd ASUOT
py -3 -m venv venv
venv\Scripts\pip install -r requirements.txt
venv\Scripts\python -m waitress --listen=0.0.0.0:8080 app:app
```
или просто запустить `run.bat` (сам создаст окружение). Для автозапуска: поставщик Task Scheduler / NSSM.

## 3. Настройки (переменные окружения)
- ASUOT_PORT — порт (по умолчанию 8080)
- ASUOT_ORG — наименование организации в шапке
- ASUOT_SECRET — секретный ключ сессий (обязательно сменить в проде!)

## 4. Безопасность
- Смените пароли демо-учетных записей сразу после установки (Профиль).
- БД: файл asuot.db — резервное копирование регулярное.
- Для продакшена используйте reverse-proxy nginx + HTTPS.

## 5. Тестирование
```bash
venv/bin/python smoke_test.py   # проходной тест всех модулей и прав доступа
```
