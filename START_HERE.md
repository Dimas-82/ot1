# 🚀 АСУ "Охрана труда" - Инструкция по запуску на Windows

## ⚡ Быстрый старт (3 минуты)

### 1️⃣ Установите Python
- Скачайте с https://www.python.org/downloads/
- **ВАЖНО:** При установке отметьте ✅ "Add Python to PATH"
- Проверьте: откройте cmd → `python --version`

### 2️⃣ Запустите установку
```
Откройте папку: backend
Дважды кликните: setup.bat
Дождитесь завершения (2-5 минут)
```

### 3️⃣ Запустите приложение
```
Дважды кликните: run.bat
Откройте браузер: http://localhost:8000
```

### 4️⃣ Войдите в систему
```
Логин: admin
Пароль: admin123
```

## ⚠️ Важные замечания

### Безопасность
1. **Измените пароль** администратора при первом входе
2. **Измените SECRET_KEY** в файле `backend/.env`
3. Для production отключите `DEBUG=true` в `.env`

### Резервное копирование
Регулярно копируйте:
- `backend/data/` - база данных
- `backend/.env` - конфигурация

### Требования
- Windows 10/11 (64-bit)
- Python 3.10 или выше
- 2 GB RAM минимум
- 1 GB свободного места

## 🆘 Решение проблем

### Python не найден
→ Переустановите Python с "Add to PATH"

### Ошибка установки
→ Запустите cmd от имени администратора

### Порт 8000 занят
→ Измените порт в `backend/main.py` (строка с `uvicorn.run`)

### База данных не создается
→ Запустите `backend/reset.bat`

### Подробная помощь
→ См. файл `backend/README_WINDOWS.md`
