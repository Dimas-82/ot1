## 🚀 Быстрый старт

### Windows

```cmd
# Вариант 1: Автоматическая установка
cd backend
setup.bat
run.bat

# Вариант 2: Быстрый старт
quickstart.bat
```

### Linux

```bash
# Автоматическая установка
sudo ./install.sh

# Или ручная установка
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
```

## 📊 Функциональность

### Модули системы

1. **Дашборд** - общая статистика и быстрый доступ
2. **Инциденты** - регистрация и расследование (4 типа)
3. **Инструктажи** - планирование и учет (5 типов)
4. **СИЗ** - выдача средств защиты
5. **Медосмотры** - планирование и контроль
6. **Модули** - управление модулями системы
7. **Маршруты** - управление API маршрутами
8. **Пользователи** - управление учетными записями
9. **Аудит** - журнал всех действий
10. **Настройки** - конфигурация системы

### Роли пользователей

- **Администратор** - полный доступ
- **Инженер по ОТ** - управление модулями ОТ
- **Руководитель** - просмотр данных подразделения
- **Работник** - просмотр своих данных
- **Аудитор** - просмотр журнала аудита

## 🔧 Технологии

### Backend
- **Python 3.10+**
- **FastAPI** - веб-фреймворк
- **SQLAlchemy** - ORM
- **SQLite** - база данных (по умолчанию)
- **JWT** - аутентификация
- **Pydantic** - валидация данных

### Frontend
- **React 18**
- **TypeScript**
- **Vite** - сборщик
- **Tailwind CSS** - стили
- **React Router** - маршрутизация

### Инфраструктура
- **Virtual Environment** - изоляция зависимостей
- **SQLite** - встроенная БД (Windows)
- **PostgreSQL** - опционально (Linux production)

## 🆘 Поддержка

При возникновении проблем:
1. Проверьте раздел "Устранение неполадок" в документации
2. Проверьте логи в папке `backend/logs/`
3. Попробуйте сбросить базу данных: `backend/reset.bat`
