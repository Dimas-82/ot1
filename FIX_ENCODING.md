## 🚀 Инструкция по запуску

### Шаг 1: Установите Python
1. Скачайте Python 3.10+ с https://www.python.org/downloads/
2. **ВАЖНО:** При установке отметьте галочку **"Add Python to PATH"**
3. Проверьте: `python --version`

### Шаг 2: Запустите установку
```
Откройте папку: backend
Дважды кликните: setup.bat
Дождитесь завершения (2-5 минут)
```

### Шаг 3: Запустите приложение
```
Дважды кликните: run.bat
Откройте браузер: http://localhost:8000
```

### Шаг 4: Войдите в систему
```
Логин: admin
Пароль: admin123
```

## ⚠️ Важные замечания

### Безопасность
1. Измените пароль администратора
2. Измените SECRET_KEY в backend/.env
3. Для production отключите DEBUG=true

### Резервное копирование
Регулярно копируйте:
- backend/data/ - база данных
- backend/.env - конфигурация

## 🆘 Решение проблем

### Python не найден
→ Переустановите Python с "Add to PATH"

### Ошибка установки
→ Запустите cmd от имени администратора

### Порт 8000 занят
→ Измените порт в backend/main.py

### База данных не создается
→ Запустите backend/reset.bat
