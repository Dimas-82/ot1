## 🚀 Как использовать

### Быстрый старт (Windows)

```cmd
1. Установите Python 3.10+ с python.org
   ⚠️ Отметьте "Add Python to PATH"

2. Откройте START_HERE.md
   Прочитайте краткую инструкцию

3. Запустите backend/setup.bat
   Дождитесь завершения установки

4. Запустите backend/run.bat
   Откройте http://localhost:8000

5. Войдите:
   Логин: admin
   Пароль: admin123
```

### Альтернативный способ

```cmd
quickstart.bat
```

Этот скрипт автоматически установит и запустит приложение.

## 🔐 Безопасность

### Рекомендации для production:
1. Измените `SECRET_KEY` в `backend/.env`
2. Измените пароли тестовых пользователей
3. Отключите `DEBUG=true` в `.env`
4. Настройте firewall Windows
5. Используйте HTTPS (дополнительная настройка)
6. Регулярно делайте резервные копии
